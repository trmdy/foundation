Apiary — Tracks pane

A track is an expected sequence of steps clipped onto one agent. The pane is where tracks are defined, watched, and edited — the list is definitions, the state on each row is the live attachments underneath them.
exploration · MACHINES_AND_TRACKS.md · design-brief.md §2 §4 §9
LEFT — THE LIVE STATE A definition has no state of its own. The dots are its attachments: one dot + label per state present, straight from the shared palette. No attachments reads plainly as “no attachments”, not as a sixth colour.
RIGHT — THE SHAPE Items are the spine you authored; nodes count the branch lanes and review arms underneath. It is the one number that tells you how big an edit you are about to open.
QUEUED Queue depth is not a property of the track — it counts bees that have this track waiting FIFO behind whatever they are attached to right now.
EXCEPTIONS A hollow brick ring, never a filled dot — deviation is visible, not punished, and it is deliberately not part of the status palette because it is not a state to be in.
One honey moment per pane: the filled Define track. Every selection, tab and count here is neutral gray.
NO BLUEPRINT LAYER A starter-template grid is the obvious empty state and the wrong one: a template layer is an explicit non-goal. So the affordance is the real verb — define one — and the fallback is an agent drafting a real definition you then judge.
TRACK ≠ MACHINE A machine is a canvas with triggers built in, holding many jobs, alive for years. A track is the small thing: one agent, one expected sequence. Tracks work on agents inside machines, but neither feature needs the other.
WHERE IT ACTUALLY LIVES The track is a real object in Honeybee. This pane is a view onto hive track define / attach / status — the footer says so quietly rather than pretending the pane owns the data.
ONE PIXEL MOMENT Art tokens are declared separately from chrome tokens on purpose: the bee may be vivid, the UI palette stays restrained, and the two never bleed into each other.
Three panes, three honey moments, one each: Define track · accept · Define a track. Never two at once.
